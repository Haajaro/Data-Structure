#  Hospital Billing System

##  About the Project
The Hospital Billing System is a Java application that manages medical service costs and calculates the total hospital bill.

## Features
- Displays medical service information.
- Shows service IDs and names.
- Calculates the total cost of medical services.
- Displays the final hospital bill.



##  Program Output

```text
===== HOSPITAL BILLING SYSTEM =====

Service ID: S001
Service: Consultation
Total Cost: $25.00

Service ID: S002
Service: Laboratory Test
Total Cost: $18.00

Service ID: S003
Service: Ultrasound
Total Cost: $40.00

------------------------------
Total Hospital Bill: $83.00
```

##  Bill Calculation

| Medical Service | Cost |
|---|---:|
| Consultation | $25.00 |
| Laboratory Test | $18.00 |
| Ultrasound | $40.00 |
| **Total Bill** | **$83.00** |
